# The Asset Steward: asset agents for Field Central

An agent on every site, an operations manager over them, and a specialist behind them.

| File | What it is |
|---|---|
| `index.html` | The proposal site |
| `ubitricity-prototype.html` | A clickable prototype of one Ubitricity street, with a demo guide, a Notchi board (`#board`) and a workspace mock (`#workspace`) |
| `asset-agents-minions.mp4` | A 77-second explainer video with voiceover |

Open `index.html` in a browser, or turn on GitHub Pages for this folder. Sites, people and numbers in the examples are made up.
